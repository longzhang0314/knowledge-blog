这个站点的目标不是把零散笔记简单搬到网上，而是把学习路径、项目经验、线上问题排查和面试表达整理成一个长期可维护的体系。

<!-- truncate -->

我会优先沉淀三类内容：

1. **底层原理**：JVM、并发、MySQL、Redis、RocketMQ 等核心技术。
2. **工程落点**：项目里为什么这样设计，风险是什么，兜底怎么做。
3. **线上排查**：从现象到止血、定位、修复、复盘的完整链路。

后续每一篇内容都会尽量按照“结论 -> 原理 -> 项目落点 -> 风险和兜底”的结构组织，让笔记不仅能复习，也能变成面试和技术分享时说得清楚的材料。
