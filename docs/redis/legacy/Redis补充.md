# Redis补充

Redis补充

1. 持久化

（1）RDB持久化：

将某个时间点的所有数据都存放到硬盘上。

可以将快照复制到另一台服务器从而创建服务器副本；如果系统发生故障，将丢失最后一次创建快照之后的数据；如果数据量很大，保存快照的时间会很长。

（2）AOF持久化：

将写命令同步到AOF命令的末尾。

执行这种同步方式时需要配置同步选项，确保文件同步到磁盘的时机。

有三种选项：

always:每次写操作都同步，这会严重降低服务器性能。

everysec:每秒同步一次，推荐的选项，每秒一次并不会对服务器性能有太大影响，并且可以保证系统崩溃时只会丢失一秒左右的数据。

no:由操作系统来决定何时同步，并不会对性能有好的影响，反而会增加系统崩溃时数据丢失的数量。

随着服务器写请求的增多，AOF文件会膨胀，Redis提供了一种将AOF重写的特性，能够去除AOF文件中的冗余命令。
