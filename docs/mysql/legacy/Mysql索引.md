### Mysql索引
1. 索引的数据结构选择：
- 散列表：单条数据查询效率高，但是缺点是每次查询需要把所有数据加载到内存中，此外，对于范围查询不太友好；
- 二叉树：二叉树可以支持高效的插入和查询操作，缺点是树的高度容易过高，会导致IO次数增加，影响查询效率。
- B树，就是N叉树，有N个子节点，这样可以减小树的高度，降低IO次数，每个节点存储数据和指针；
- B+树：与B树结构类似，不同的地方在于非叶子节点只存储唯一键和指针，叶子节点存储完整的数据。对于Mysql一个节点16K的大小来说，只存储唯一键和指针存储的数据条数远大于存储完整的数据，所以B+树的存储效率是更高的。
2. Mysql索引的分类：
- 主键，唯一索引，普通索引；
- 从索引的组织形式来分还可以有聚簇索引（InnoDB）:索引和数据在同一个文件，这样读取效率更高；非聚簇索引（MyISAM）：索引和数据分开存放，导致数据是碎片化的，效率低于聚簇索引。
