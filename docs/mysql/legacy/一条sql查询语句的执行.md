### 一条sql查询语句的执行
1. Mysql逻辑架构
- Server层和存储层：Server层包括连接器，分析器，优化器，执行器；存储层为存储引擎。 
- 连接器：通过用户名密码连接客户端和服务器。
- 分析器：词法分析，是否存在查询的行和列，语法语义分析。
- 优化器：进行查询效率优化，包括表连接是先查A表还是先查B表等问题。
- 执行器：进行索引选择，权限校验，查询存储引擎，返回执行结果等操作。
- 存储引擎：mysql5.7默认InnoDB,相比于MyISAm,支持事务。
2. Server层和存储引擎层的作用。
- Server层：执行语句分析，优化，判断，索引选择，权限校验的操作。
- 存储引擎：存储数据。
3. you have an error in your SQL syntax 这个保存是在词法分析里还是在语法分析里报错?
- 语法分析。
4. 对于表的操作权限验证在哪里进行？
- 执行器。
5. 执行器的执行流程?
- 调用InnoDB引擎接口，判断ID=x的第一行是否是要查找的值。
- 查看下一行是否争取。
- 返回所有正确的结果。
