#### 模板模式

- 在父类方法中处理统一逻辑，采用抽象方法处理不同子类的逻辑，一般结合工厂模式或者策略模式进行使用。

```java
// 代码来源于争哥设计模式
public abstract class AbstractClass &#123;
  public final void templateMethod() &#123;
    //...
    method1();
    //...
    method2();
    //...
  &#125;
  
  protected abstract void method1();
  protected abstract void method2();
&#125;

public class ConcreteClass1 extends AbstractClass &#123;
  @Override
  protected void method1() &#123;
    //...
  &#125;
  
  @Override
  protected void method2() &#123;
    //...
  &#125;
&#125;

public class ConcreteClass2 extends AbstractClass &#123;
  @Override
  protected void method1() &#123;
    //...
  &#125;
  
  @Override
  protected void method2() &#123;
    //...
  &#125;
&#125;

AbstractClass demo = ConcreteClass1();
demo.templateMethod();
```

- **应用1-代码复用**：

    - InputStream源码，read(byte b[], int off, int len)方法
    
    ```java
    if (b == null) &#123;
        throw new NullPointerException();
    &#125; else if (off &lt; 0 || len &lt; 0 || len > b.length - off) &#123;
        throw new IndexOutOfBoundsException();
    &#125; else if (len == 0) &#123;
        return 0;
    &#125;

    int c = read();
    if (c == -1) &#123;
        return -1;
    &#125;
    b[off] = (byte)c;

    int i = 1;
    try &#123;
        for (; i &lt; len ; i++) &#123;
            c = read();
            if (c == -1) &#123;
                break;
            &#125;
            b[off + i] = (byte)c;
        &#125;
    &#125; catch (IOException ee) &#123;
    &#125;
    return i;
    
    public abstract int read() throws IOException;
    ```
    - AbstractList的addAll()方法：
    
    ```java
    public boolean addAll(int index, Collection&lt;? extends E> c) &#123;
        rangeCheckForAdd(index);
        boolean modified = false;
        for (E e : c) &#123;
            add(index++, e);
            modified = true;
        &#125;
        return modified;
    &#125;
    
    public void add(int index, E element) &#123;
        throw new UnsupportedOperationException();
    &#125;
    ```
- **应用2-代码复用**

    - Servlet：继承HttpServlet类，实现doGet()方法和doPost()方法，不需要关心一次调用的其他实现，也方便进行扩展。
    
    请求入口在HttpServlet类的service()方法，内部去调用doGet()和doPost()。
    
    ```java
    public class HelloServlet extends HttpServlet &#123;
      @Override
      protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException &#123;
        this.doPost(req, resp);
      &#125;
      
      @Override
      protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException &#123;
        resp.getWriter().write("Hello World.");
      &#125;
    &#125;
    ```
- 弊端：如果有多个抽象模板方法，但是并非每一个子类都需要实现，可以采用适配器模式；写个适配器，把所有抽象方法进行默认实现，子类继承这个adapter就可以。

    在 spring生命周期中，InstantiationAwareBeanPostProcessorAdapter就是解决这个问题的。
