#### 适配器模式

将本不兼容的接口转换为可兼容的接口，让原本由于接口不兼容而不能共同工作的类可以一起工作。

两种实现：类适配器和对象适配器。

最终需要工作的是ITarget接口，Adaptor是适配器的具体实现，Adaptee是不兼容ITarget定义的接口。

**类适配器**：采用继承实现。

```java
// 类适配器: 基于继承
public interface ITarget &#123;
  void f1();
  void f2();
  void fc();
&#125;

public class Adaptee &#123;
  public void fa() &#123; //... &#125;
  public void fb() &#123; //... &#125;
  public void fc() &#123; //... &#125;
&#125;

public class Adaptor extends Adaptee implements ITarget &#123;
  public void f1() &#123;
    super.fa();
  &#125;
  
  public void f2() &#123;
    //...重新实现f2()...
  &#125;
  
  // 这里fc()不需要实现，直接继承自Adaptee，这是跟对象适配器最大的不同点
&#125;
```

**对象适配器**：采用组合实现。

```java
// 对象适配器：基于组合
public interface ITarget &#123;
  void f1();
  void f2();
  void fc();
&#125;

public class Adaptee &#123;
  public void fa() &#123; //... &#125;
  public void fb() &#123; //... &#125;
  public void fc() &#123; //... &#125;
&#125;

public class Adaptor implements ITarget &#123;
  private Adaptee adaptee;
  
  public Adaptor(Adaptee adaptee) &#123;
    this.adaptee = adaptee;
  &#125;
  
  public void f1() &#123;
    adaptee.fa(); //委托给Adaptee
  &#125;
  
  public void f2() &#123;
    //...重新实现f2()...
  &#125;
  
  public void fc() &#123;
    adaptee.fc();
  &#125;
&#125;
```

**应用场景**:

- 封装有缺陷的接口设计，对外提供更安全的接口，不提供不必要的功能；

- 统一多个类的接口设计，方便进行代码复用（例如：王争设计模式-敏感词过滤）。如果需要进行链式调用同一类方法，可以先使用多态+适配器的方式构造多个实现。客户端调用时可以一次调用所有的实现。

- 替代依赖的外部系统：对原本的接口增加一个新的实现，调用新的实现。

- 兼容老版本接口：改造老版本接口，通过适配器的方式，在老版本中直接使用新版本功能。

- 适配不同格式的数据
    ```java
    List&lt;String> stooges = Arrays.asList("Larry", "Moe", "Curly");
    ```

**适配器模式可以看作一种“补偿模式”，用来补救设计上的缺陷。**
