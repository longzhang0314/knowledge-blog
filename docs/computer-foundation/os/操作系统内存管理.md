# 操作系统内存管理

操作系统内存管理

操作系统内存管理指的是操作系统对内存的分配，回收以及地址转换（逻辑地址转换为物理地址）。

一、常见的内存管理机制

分为连续分配管理方式和非连续分配管理方式，连续分配管理方式指的是给一个用户程序分配连续的内存空间，如块式管理；非连续分配管理方式允许内存是非连续的或离散的，如页式管理和段式管理。

1. 块式管理：操作系统把内存分成一块一块，每个应用程序需要使用时分配一块，每个块中只包含一个进程，如果当前应用程序运行需要的内存较小，会造成块中部分内存被浪费，称为碎片。

2. 页式管理：把主存划分为一页一页的大小，页比块的划分力度更大，提高了内存利用率，减少了碎片的产生，页表中存储逻辑地址和物理地址的对应关系。

3. 段式管理：页式管理进行的是物理上的划分，每个页并无实际意义。端式管理通过逻辑意义的不同进行划分，每一段的大小比一页的空间小很多。例如有主程序段 MAIN、子程序段 X、数据段 D 及栈段 S 等。段式管理通过段表对应逻辑地址和物理地址。

4. 段页管理：结合页式管理和段式管理的优点，先把主存进行段式划分，然后每一段再进行页式划分，每一段和每一段之间都是离散的，每一段内部也是离散的。
