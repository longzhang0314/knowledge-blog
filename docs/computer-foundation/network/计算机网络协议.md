# 计算机网络协议

计算机网络协议

1. 七层协议划分（OSI）：应用层，表示层，会话层，运输层，网络层，数据链路层，物理层；

2. 五层协议划分：应用层，运输层，网络层，数据链路层，物理层；

3. TCP/IP划分：应用层，运输层，网际层，网络接口层。
