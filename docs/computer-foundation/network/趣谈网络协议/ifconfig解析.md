# ifconfig解析

IP是地址，用于定位；MAC是身份证，无定位功能。

CIDR中前面的是网络号，后面的是主机号。

IP地址和子网掩码AND运算可以得到网络号。

公有IP和私有IP。

MAC层通信通过内核提供的队列排队发送。
