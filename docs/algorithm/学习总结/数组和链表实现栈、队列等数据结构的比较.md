### 数组和链表实现栈、队列等数据结构的比较

对于Queue、Deque这种数据结构，都可以通过LinkedList或者ArrayDeque来实现，区别是什么呢？

对于链表来说，插入时间复杂度是O(1)的；对于数组来说，插入的平均时间复杂度也是O(1)的，但是在需要扩容时是O(N)的，这么说链表插入大数据的性能是优于数组的，我们做个实验：

```java
Deque&lt;Integer> stack1 = new ArrayDeque&lt;>();
Deque&lt;Integer> stack2 = new LinkedList&lt;>();

long start1 = System.currentTimeMillis();
for (int i = 0; i &lt; 10000000; i++) stack1.push(1);
long end1 = System.currentTimeMillis();

System.out.println("数组实现耗时：" + (end1 - start1));

long start2 = System.currentTimeMillis();
for (int i = 0; i &lt; 10000000; i++) stack2.push(1);
long end2 = System.currentTimeMillis();

System.out.println("链表实现耗时：" + (end2 - start2));

// 打印结果
// 数组实现耗时：116
// 链表实现耗时：2117
```
对于上面的结果，无论是先插入并打印stack1，还是先插入并打印stack2，数组实现的性能总是优于链表的。

因为链表在插入元素时，需要先去new一个Node对象，这涉及到了对内存的操作，而对内存的操作是非常慢的。

所以，在面对大规模数据的操作时，对于时间复杂度相同的操作，我们优先使用数组而非链表。
