### 位运算

**136. 只出现一次的数字**

给定一个整数数组，只有一个元素出现一次，其余出现两次，找出这个元素的值。

分析：亦或运算(相同为0，不同为1)

a^b^a=a^a^b=b

```java
public int singleNumber(int[] nums) &#123;
    int res = nums[0];
    for (int i = 1; i &lt; nums.length; i++) &#123;
        res ^= nums[i];
    &#125;
    return res;
&#125;
```
