#### 贪心

**跳跃游戏**

给定一个数组，从索引0的位置开始，每次可以跳小于等于当前位置value步，问最终能不能跳到索引n-1；

方法1：回溯。

从第一个位置开始，每次尝试跳1到value步，如果能跳到大于等于n-1的位置就返回true；一个visted数组保存跳过的位置，如果重复跳到同一个位置就返回false；

```java
public boolean canJump(int[] nums) &#123;
    boolean[] visted = new boolean[nums.length];
    return canJump(nums, visted, 0);
&#125;

private boolean canJump(int[] nums, boolean[] visted, int index) &#123;
    int n = nums.length;
    if (index >= n - 1) return true;
    if (visted[index]) return false;
    visted[index] = true;
    for (int i = index + nums[index]; i >= 1; i--) &#123;
        if (canJump(nums, visted, i)) return true;
    &#125;
    return false;
&#125;
```

方法2：贪心

```java
public boolean canJump(int[] nums) &#123;
    int n = nums.length;
    // 每个位置最大可到达i+nums[i]，那么左边的位置都可达
    // 遍历发现如果当前这个位置没有到达过，就返回false
    int k = 0;
    for (int i = 0; i &lt; n; i++) &#123;
        // 说明前面的跳跃到不了i这个位置
        if (i > k) return false;
        k = Math.max(k, i + nums[i]);
    &#125;
    return true;
&#125;
```
