**445. 两数相加**

给定两个链表，每个节点一个个位数，认为一个链表是一个数字，让两个链表相加，得到和的链表。原链表不能改变。

因为加法运算是从个位开始加，但是链表只有后继指针，所以考虑使用栈来存储每个链表的节点值。


方法1：使用3个栈，分别存储l1,l2,sum从个位开始的值。最后从sum的栈中取出元素形成链表。
