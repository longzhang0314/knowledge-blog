#### 二叉搜索树总结

**783. 二叉搜索树结点最小距离**

因为是一颗二叉搜索树，所以中序遍历结果是一个有序数组，所以要找到两个节点的最小距离，其实问题就转化为找到任意相邻节点的最小距离。

通过一个指针记录前一个节点的最小距离，中序遍历，不断更新全局最小距离即可。

```java
int min = Integer.MAX_VALUE;
//如果pre定义成局部遍历会导致出错
Integer pre = null;
public int minDiffInBST(TreeNode root) &#123;
    //中序遍历去给min赋值
    recursion(root);
    return min;
&#125;

private void recursion(TreeNode root) &#123;
    if (root == null) return;
    minDiffInBST(root.left);
    if (pre != null) min = Math.min(root.val - pre, min);
    pre = root.val;
    minDiffInBST(root.right);
&#125;
```

**938. 二叉搜索树的范围和**

当做普通二叉树处理：前序遍历，对当前节点的处理方式是如果在范围内，sum就加上当前节点的值，然后把左子树和右子树的处理交给框架解决。

```java
public int rangeSumBST(TreeNode root, int L, int R) &#123;
    if (root == null) return 0;
    int sum = 0;
    if (root.val >= L && root.val &lt;= R) &#123;
        sum += root.val;
    &#125;
    return sum + rangeSumBST(root.left, L, R) + rangeSumBST(root.right, L, R);
&#125;

```

利用二叉搜索树性质处理：前序遍历，如果当前值比L小，只考察右子树即可，反之同理；否则的话当前值有效，并递归考察左子树和右子树。

```java
public int rangeSumBST(TreeNode root, int L, int R) &#123;
    if (root == null) return 0;
    if (root.val &lt; L) return rangeSumBST(root.right, L, R);
    if (root.val > R) return rangeSumBST(root.left, L, R);
    return root.val + rangeSumBST(root.left, L, R) + rangeSumBST(root.right, L, R);
&#125;
```

**98. 验证二叉搜索树**

验证一棵树是二叉搜索树，就从根节点开始，如果每个值都符合一定的范围，就是正确的；

方法一：可以通过前序遍历，先考察根节点，之后不断收缩范围。

```java
public boolean isValidBST(TreeNode root) &#123;
    return isValidBST(root, null, null);        
&#125;

private boolean isValidBST(TreeNode root, Integer min, Integer max) &#123;
    if (root == null) return true;
    if (min != null && root.val &lt;= min) return false;
    if (max != null && root.val >= max) return false;
    return isValidBST(root.left, min, root.val) &&
        isValidBST(root.right, root.val, max);
&#125;
```
方法二：通过中序遍历，顺序考察当前节点和前一个节点的大小关系，通过辅助遍历记录前一个节点的值。

```java
//如果pre定义成局部遍历会导致出错
Integer pre = null;
public boolean isValidBST(TreeNode root) &#123;
   if (root == null) return true;
    //考察左子树
    boolean left = isValidBST(root.left);
    //考察当前节点，如果false直接返回，如果是true继续往下走
    if (pre != null && pre >= root.val) return false;
    pre = root.val;
    //考察右子树
    boolean right = isValidBST(root.right);
    return left && right;
&#125;
```

**235. 二叉搜索树的最近公共祖先**

方法一：可以按照普通的二叉树来进行，参考二叉树的笔记。

方法二：前序遍历，判断当前节点和p，以及q的关系，利用二叉搜索树的性质，可以只考察左子树或只考察右子树。

1.递归实现：
```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) &#123;
    if (root == null) return root;
    if (p.val &lt; root.val && q.val &lt; root.val) return lowestCommonAncestor(root.left, p, q);
    if (p.val > root.val && q.val > root.val) return lowestCommonAncestor(root.right, p, q);
    return root;
&#125;
```
2. 非递归实现
```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) &#123;

        if (p.val &lt; root.val && q.val &lt; root.val) &#123;
            root = root.left;
        &#125; else if (p.val > root.val && q.val > root.val) &#123;

        &#125; else &#123;
```

**1038. 从二叉搜索树到更大和树**

题目意思是更新二叉搜索树每个节点的值，让每个节点的新值等于它自身的旧值加上它后一个节点的新值。

利用BST的性质，使用中序遍历，右->中->左的顺序进行遍历，保证倒序排序。

```java
int lastValue;
public TreeNode bstToGst(TreeNode root) &#123;
    bst(root);
    return root;
&#125;

private bst(TreeNode root) &#123;
    if (root == null) return root;
    bst(root.right);
    root.val += lastValue;
    lastValue = root.val;
    bst(root.left);
&#125;
```

**1382. 将二叉搜索树变平衡**

对于一颗不平衡的二叉搜索树，先通过中序遍历构建一个有序数组，然后想办法把这个有序数组再构建成平衡的二叉搜索树。

构建平衡二叉搜索树可以每次取数组的中间值作为根节点，然后递归取左半边的中间值作为左子节点，右半边的中间值作为右子节点。

```java
public TreeNode balanceBST(TreeNode root) &#123;
    List&lt;Integer> list = new ArrayList&lt;>();
    //构建有序数组
    buildList(root, list);
    //通过有序数组构建平衡二叉搜索树
    TreeNode root = buildTree(list, 0, list.size() - 1);
    return root;
&#125;

private void buildList(TreeNode root, List&lt;Integer> list) &#123;
    if (root == null) return;
    buildList(root.left, list);
    list.add(root.val);
    buildList(root.right, list);
&#125;

private TreeNode buildTree(List&lt;Integer> list, int start, int end) &#123;
    if (start > end) return null;
    int mid = (start + end) >>> 1;
    TreeNode root = new TreeNode(list.get(mid));
    root.left = buildTree(list, start, mid - 1);
    root.right = buildTree(list, mid + 1, end);
    return root;
&#125;
```

**230. 二叉搜索数中第K小的元素**

方法1：中序遍历，count计数，count等于k时的元素就是想要的值。

```java
int res;
int count;
public int kthSmallest(TreeNode root, int k) &#123;
    kth(root, k);
    return res;
&#125;

private void kth(TreeNode root, int k) &#123;
    if (root == null) return;
    kth(root.left, k);
    if (++count == k) &#123; //表示到达第k个数了
        res = root.val;
        return;
    &#125;
    kth(root.right, k);
&#125;
```

方法2：对左子树的节点个数进行计数，如果它+1正好等于k，那我们要找的第K小的元素就是根节点；如果它+1小于k,那需要的结果就在右子树中，反之在左子树中。交给框架递归即可。

需要注意，在右子树中递归查找时，要找的不是第K小的元素，而是第k-(左子树节点个数+1)小的数。

```java
public int kthSmallest(TreeNode root, int k) &#123;
    //统计左子树的节点个数
    int leftCount = count(root.left);
    if (leftCount + 1 == k) &#123;
        return root.val;
    &#125; else if (leftCount + 1 &lt; k) &#123;
        return kthSmallest(root.right, k - (leftCount + 1));
    &#125; else &#123;
        return kthSmallest(root.left, k);
    &#125;
&#125;

private int count(TreeNode node) &#123;
    if (node == null) return 0;
    return count(node.left) + count(node.right) + 1;
&#125;
```

**1373. 二叉搜索子树的最大键值和**

给定一颗二叉树，返回里面能成二叉搜索树的子树的节点之和。

我们可以从根节点开始判断是不是一颗二叉树，如果是，直接求和返回即可；如果不是，递归处理左子树和右子树，最后取左右子树的较大值返回。

```java
int res;
public int maxSumBST(TreeNode root) &#123;
    //如果是二叉搜索树，直接求和
    if (isBST(root, null, null)) &#123;
        sum(root);
        return res;
    &#125;
    //如果不是二叉搜索树，递归考察左右子树
    int left = maxSumBST(root.left);
    int right = maxSumBST(root.right);
    return Math.max(left, right);
&#125;

private int sum(TreeNode root) &#123;
    if (root == null) &#123;
        res = Math.max(res, 0); 
        return res;
    &#125;
    int sum = root.val + sum(root.left) + sum(root.right);
    res = Math.max(res, sum);
    return sum;
&#125;

private boolean isBST(TreeNode root, Integer min, Integer max) &#123;
    if (root == null) return true;
    if (min != null && root.val &lt;= min) return false;
    if (max != null && root.val >= max) return false;
    return isBST(root.left, min, root.val) && isBST(root.right, root.val, max);
&#125;
```
