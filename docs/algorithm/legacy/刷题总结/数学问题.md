#### 数学问题

**892. 三维型体的表面积**

题目给出一个二维数组表示地面的大小，即地面上单元格的分布，二维数组的值表示每个单元格重叠起来放几个，每个立方体是1*1*1的，求最后组成的三维型体的表面积。

可以考虑用减法计算，先求出所有的立方体总表面积，然后减去重叠部分的面积；每两个立方体重叠一个面，就需要减去2的表面积，所以题目转化为求重叠的面有多少个。

垂直方向重叠面个数为该单元格放置的立方体个数-1；

同一行（比如第0行）的重叠面个数为同一行每相邻两列垂直放置的较小值，依次累加；

同一列的重叠面个数为同一列每相邻两行垂直放置的较小值，依次累加。

```java
public int surfaceArea(int[][] grid) &#123;
    if (grid == null || grid.length == 0 || grid[0].length == 0) return 0;
    int row = grid.length;
    int col = grid[0].length;
    //所有立方体的个数
    int sum = 0;
    //同一个单元格垂直重叠的个数,每两个重叠计一个数
    int verticalSum = 0;
    //行重叠的个数
    int rowSum = 0;
    //列重叠的个数
    int colSum = 0;

    for (int i = 0; i &lt; row; i++) &#123;
        for (int j = 0; j &lt; col; j++) &#123;
            sum += grid[i][j];
            //同一个单元格重叠个数：总个数-1
            if (grid[i][j] > 0) verticalSum += (grid[i][j] - 1);
            //该行每相邻两列的重叠个数：每相邻两列的立方体个数取较小值
            if (j > 0) rowSum += Math.min(grid[i][j - 1], grid[i][j]);
            //该列每相邻两行的重叠个数：每相邻两行的立方体个数取较小值
            if (i > 0) colSum += Math.min(grid[i - 1][j], grid[i][j]);
        &#125;
    &#125;
    return sum * 6 - (verticalSum+ rowSum + colSum) * 2;
&#125;
```

**914. 卡牌分组**

题意：给定一个卡牌数组，给定一个数n, 相同的数分为一组，求是否存在这样一个大于等于2的数。数组的大小小于10000。

分析：对数组中出现的每个数进行计数，求这些计数的最大公约数是不是大于等于2。

```java
public boolean hasGroupsSizeX(int[] deck) &#123;
    if (deck == null || deck.length &lt;= 1) return false;
    //计数数组
    int[] counter = new int[10000];
    for (int d : deck) &#123;
        counter[d]++;
    &#125;
    //遍历求最大公约数, 初始化第一个元素
    int x = counter[deck[0]];
    for (int c : counter) &#123;
        x = gcd(x, c);
        if (x &lt; 2) return false;
    &#125;
    return true;
&#125;
//求最大公约数
//辗转相除法：m和n的最大公约数=n和m%n的最大公约数
private int gcd(int a, int b) &#123;
    return b == 0 ? a : gcd(b, a % b);
&#125;
```
**圆圈中最后剩下的数字**

给定一个0到n-1的数组，每次删除第m个元素，问最后剩下的是多少。

方法1：模拟一个链表，每次把前m-1个数放到链表尾部，删除第m个，直到最后剩余一个元素。

```java
public int lastRemaining(int n, int m) &#123;
    List&lt;Integer> list = new ArrayList&lt;>();
    for (int i = 0; i &lt; n; i++) &#123;
        list.add(i);
    &#125;
    //每次将第m之前的元素插到链表尾部，删除第m个，下次循环第m+1个元素在头部
    while (list.size() > 1) &#123;
        for (int j = 0; j &lt; m; j++) &#123;
            //先放到尾部，后删除
            if (j != m - 1) list.add(list.get(0));
            list.remove(0);
        &#125;
    &#125;
    return list.get(0);
&#125;
```
方法2： 每次找到删除的第m个元素后，下一个元素的索引为当前的+m再-1，-1是因为删除该元素后后面的整体前移一位，防止索引越界，需要对当前list的size取模。
```java
public int lastRemaining(int n, int m) &#123;
    List&lt;Integer> list = new ArrayList&lt;>();
    for (int i = 0; i &lt; n; i++) &#123;
        list.add(i);
    &#125;
    // 每次删除后标记下一个索引位置，idx + m - 1 (-1是因为删除后后面的元素都往前移动了一位)，
    // 超出范围后从头开始数，所以对list的长度取模
    int idx = 0;
    while (list.size() > 1) &#123;
        idx = (idx + m - 1) % list.size();
        list.remove(idx);
    &#125;
    return list.get(0);
&#125;
```

方法3：递推法。因为最后肯定只剩自己并且索引是0，那么上一轮它肯定是第m+1个元素，因为前m个删除或放到尾部了。

所以索引的递推公式就是：index = (index + m) % 当前的数组长度；当前数组长度从2开始，到等于n为止。

```java
//从最后只剩自己向上递推，递推到有n个元素是自己的位置
int res = 0;
public int lastRemaining2(int n, int m) &#123;
    //倒数第二轮有两个元素
    process(n, m, 2);
    return res;
&#125;

private void process(int n, int m, int sum) &#123;
    if (sum == n + 1) return;
    //前一轮索引是res,当前这轮就是res+m，因为前面删除了m个
    res = (res + m) % sum;
    process(n, m, sum + 1);
&#125;
```

方法4：方法3的非递归写法

```java
public int lastRemaining2(int n, int m) &#123;
   int res = 0;
   for (int i = 2; i &lt;= n; i++) &#123;
       res = (res + m) % i;
   &#125;
   return res;
&#125;
```

**231 2的幂**

判断给定的整数n是否是2的幂次方。

方法1：判断当前余2是否等于0？等于0的话原数除以2继续判断，直到最终除完后判断剩余的数是否为1.

```java
public boolean isPowerOfTwo(int n) &#123;
    if (n &lt;= 0) return false;
    while (n % 2 == 0) &#123;
        n /= 2;
    &#125;
    return n == 1;
&#125;

```

方法2：位运算。一个数x如果是2的n次幂，那么x & (x - 1) == 0.

```java
public boolean isPowerOfTwo(int n) &#123;
    return n > 0 && ((n & (n - 1)) == 0);
&#125;

```
