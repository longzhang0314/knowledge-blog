**784. 字母大小写全排列**

需要选到所有的字母大小写转换后的字符串，所有使用回溯，每考察一个字符，先将它选中往下走；如果是字符，再将它转为大写或小写往下走另一个分支。

大小写转换的方式：char[i] ^ 32

```java
public List&lt;String> letterCasePermutation(String S) &#123;

    solve(S.toCharArray(), res, 0);
    return res;
&#125;

private void solve(char[] cc, List&lt;String> res, int i) &#123;
    int n = cc.length;
    if (i == n) &#123;
        res.add(new String(cc));
        return;
    &#125;
    //什么都不改变，考察下一个数
    solve(cc, res, i + 1);
    //转换大小写后考察下一个数
    if (cc[i] &lt; '0' || cc[i] > '9') &#123;
        //转换当前数的大小写
        cc[i] ^= (1 &lt;&lt; 5);
        solve(cc, res, i + 1);
    &#125;
&#125;
```

```java

private void process(int[] candidates, int target, List&lt;Integer> list, int start) &#123;
    if (target &lt; 0) return;
    if (target == 0) &#123;
        res.add(new ArrayList&lt;>(list));
        return;
    &#125;
    for (int i = start; i &lt; candidates.length; i++) &#123;
        //保证同一层不会有重复元素，但又不会对不同层剪枝

        if (i > start && candidates[i] == candidates[i - 1]) continue;

```

针对这一问题提炼出回溯模板：先定义一个全局返回变量，做一些特判，定义返回值内部的小集合，套用递归模板向全局变量赋值。

递归方法中，先写出递归终止条件，再判断当前元素如何处理，然后递归处理下一个元素，递归回来后恢复现场。

**模板：**

```java
esult = []
def backtrack(路径, 选择列表):
    if 满足结束条件:
        result.add(路径)
        return
    for 选择 in 选择列表:
        做选择
        backtrack(路径, 选择列表)
        撤销选择
```

**77. 组合**

给定两个整数 n 和 k，返回 1 ... n 中所有可能的 k 个数的组合。

按照上面的模板来套一下。

n = 100, k= 90, i = 15，list 里面现有3个数据，还剩86次循环，但要达到k还需要87个元素，所有后面会有86次无效循环。

需要减枝，循环中 i &lt;= n 的条件稍微修改一下，改成：

i - 1 + (k - list.size()) &lt;= n; 

意思是在当前已经考察过前 i - 1 个元素了，list里面还需要 k - list.size() 个元素，加起来如果小于等于 n 就可以继续考察，否则就退出循环。

剪枝：

**17. 电话号码中的字符组合**

每个数字对应一个字符串，我们要得到所有的数字对应的字符串组合，很容易想到嵌套for循环；但是这里没法知道嵌套几层，所以使用回溯的方法。

从给定字符串的第一个元素进行考察，循环遍历它对应的字符串的每个字符，每选中一个，递归考察下一个给定数字。

时间复杂度O(3 ^ n)，空间复杂度O(N)

```java
//字典
private String[] letterMap = &#123;"abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"&#125;;
private List&lt;String> res;
public List&lt;String> letterCombinations(String digits) &#123;
    res = new ArrayList&lt;>();
    if (digits == null || digits.trim().length() == 0) return res;
    //存储每次到达叶子节点时走过的路径
    StringBuilder sb = new StringBuilder();
    process(digits, sb, 0);
    return res;
&#125;

//index表示考察到digits的索引位置
private void process(String digits, StringBuilder sb, int index) &#123;
    //递归终止条件，到达叶子节点了
    if (index == digits.length()) &#123;
        res.add(sb.toString());
        return;
    &#125;

    //获取当前digits字符对应字典表的字符串
    char c = digits.charAt(index);
    //第一个位置存储的是2对应的字符串
    int mapIndex = c - '2';
    String mapValue = letterMap[mapIndex];

    //循环处理
    for (int i = 0; i &lt; mapValue.length(); i++) &#123;
        sb.append(mapValue.charAt(i));
        //递归考察digits下一个字符对应的字符串，相当于又嵌套一层for
        process(digits, sb, index + 1);
        //恢复现场
        sb.deleteCharAt(sb.length() - 1);
    &#125;
&#125;
```
**79. 单词搜索**

题意：给定一个单词和一个二维字符，问二维数组中是否存在一条路径，可以构成这个单词。行走路径只能向上下左右方向，且不能重复。

根据题意，使用回溯的方法。遍历二维数组获得任意一个起点，然后从起点开始对4个方向dfs，当dfs的长度等于字符串的长度并且相等时返回true,否则回溯。

需要一个长度为字符数组长度的数组存储是否在该条dfs路径上已经访问过，一个容量为4的方向数组。

```java
//存储在一条dfs路径上组成单词的点
private boolean[][] visted;
private int m;
private int n;
private int[][] directions = &#123;&#123;-1, 0&#125;, &#123;1, 0&#125;, &#123;0, -1&#125;, &#123;0, 1&#125;&#125;;
public boolean exist(char[][] board, String word) &#123;
    if (board == null) return false;
    m = board.length;
    if (m == 0) return false;
    n = board[0].length;
    visted = new boolean[m][n];
    //遍历的是单词的起点，不断尝试起点是否合适
    for (int i = 0; i &lt; m; i++) &#123;
        for (int j = 0; j &lt; n; j++) &#123;
            if (dfs(board, word, i, j, 0)) return true;
        &#125;
    &#125;
    return false;
&#125;

private boolean dfs(char[][] boards, String words, int i, int j, int index) &#123;
    //如果到达单词的最后一个索引，直接在此处判断返回
    if (index == words.length() - 1) return words.charAt(index) == boards[i][j];
    //如果当前合理，继续往下递归
    if (boards[i][j] == words.charAt(index)) &#123;
        visted[i][j] = true;
        //当前合理，所以递归向下考察，分4个方向
        for (int k = 0; k &lt; 4; k++) &#123;
            int ii = i += directions[k][0];
            int jj = j += directions[k][1];
            //如果没走到边界并且没访问过
            if (inArea(ii, jj) && !visted[ii][jj]) &#123;
                //继续向下dfs，如果返回false,恢复现场
                if (dfs(boards, words, ii, jj, index + 1)) return true;
            &#125;
        &#125;
        visted[i][j] = false;
    &#125;
    return false;
&#125;

private boolean inArea(int i, int j) &#123;
    return i >= 0 && i &lt; m && j >= 0 && j &lt; n;
&#125;
```

**60. 第k个排列**

给出集合 [1,2,3,…,n]，其所有元素共有 n! 种排列;

给定 n 和 k，返回第 k 个排列。

方法1：先给出全排列，最后选中第k个。但这样性能较差，很多无意义的路径被找出来。

方法2：DFS。只需要找出一个符合题意的即可，中途加上剪枝。

对于n个数，有n!种排列，每选中一个数，后续剩余就有(n-1)!种排列；我们先选中第一个数，比较(n-1)!和k的关系，如果小于k，那么第一个数开头的数都被剪枝，然后考察同一层下一个数开头；当前层开头元素选中以后，再递归去考察下一层，层数=n时递归终止。

我们需要一个阶乘数组记录1到n的阶乘，0的阶乘本题可以认为0，剩下0个数时可选择的就是1,；需要一个记录层数的变量；为了不重复，还需要一个记录已选中的数组。

```java
// 一次dfs即可
public String getPermutation(int n, int k) &#123;
    int[] arr = new int[n];
    int[] factorial = new int[n + 1];
    factorial[0] = 1;
    for (int i = 1; i &lt;= n; i++) &#123;
        factorial[i] = i * factorial[i - 1];
    &#125;
    boolean[] used = new boolean[n + 1];
    dfs(n, k, arr, factorial, used, 0);
    StringBuilder sb = new StringBuilder();
    for (int num : arr) &#123;
        sb.append(num);
    &#125;
    return sb.toString();
&#125;

// index考察第Index层
private void dfs(int n, int k, int[] arr, int[] factorial, boolean[] used, int index) &#123;
    if (index == n) return;
    //第index层选中默认选中第0个数时叶子结点个数
    int fac = factorial[n - index - 1];
    for (int i = 1; i &lt;= n; i++) &#123;
        if (used[i]) continue;
        //第0个分支（i = 1）叶子总数小于k
        if (k > fac) &#123;
            //在同一层下个分支找第k-fac的组合
            k -= fac;
            continue;
        &#125;
        used[i] = true;
        arr[index] = i;
        //找下一层
        dfs(n, k, arr, factorial, used, index + 1);
    &#125;
&#125;
```
