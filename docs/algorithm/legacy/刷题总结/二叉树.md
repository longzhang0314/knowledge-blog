#### 二叉树总结

**111. 二叉树最小深度**


二叉树最小深度就是左子树和右子树的最小深度，再+1（加上根节点），所以本题可以采用前序遍历的方法，但是要注意，如果左子树深度为0或者右子树深度为0，我们就放弃这条子树，结果只和另一条子树相关。

```java
public int minDepth(TreeNode root) &#123;
    if (root == null) return 0;
    int left = minDepth(root.left);
    int right = minDep(root.right);
    return left == 0 || right == 0 ?
        left + right + 1 :
        Math.min(left, right) + 1;
&#125;
```

**236. 二叉树的最近公共祖先**

先考察根节点，如果p或者q就是根节点，那根节点就是公共祖先。否则的话，考察它的左子树和右子树。

有两种情况，第一种情况要么p和q都在左子树，那公共祖先就在左子树，右子树同理；第二种情况p和q分散在左右子树，那么公共祖先只能是根节点。

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) &#123;
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    return left == null ? right : right == null ? left : root;    
&#125;
```

**101. 对称二叉树**

根节点做特殊处理，如果为null肯定是对称的，之后向下考察左子树和右子树是否对称。

左右子树都不为空的情况下，考察左子树左边与右子树右边（外），以及左子树右边和右子树左边（内）是否对称，之后的事情交给递归框架即可。

```java
public boolean isSymmetric(TreeNode root) &#123;
    if (root == null) return true;
    return isSymetric(root.left, root.right);
&#125;

private boolean isSymmetric(TreeNode left, TreeNode right) &#123;
    if (left == null && right == null) return true;
    if (left == null || right == null) return false;
    boolean cur = left.val == right.val;
    boolean out = isSymmetric(left.left, right.right);
    boolean in = isSymmetric(left.right, right.left);
    return out && in;
&#125;
```

**102. 二叉树的层次遍历**

这道题有两种做法，可以使用BFS逐层遍历，也可以使用DFS，但注意在DFS时需要带一个参数：当前层的层数。

DFS解法：

```java
public List&lt;List&lt;Integer>> levelOrder(TreeNode root) &#123;
    List&lt;List&lt;Integer>> res = new ArrayList&lt;>();
    levelOrder(root, res, 0);
    return res;
&#125;

private void levelOrder(TreeNode root, List&lt;List&lt;Integer>> res, int level) &#123;
    if (root == null) return;
    //判断当前层是否还没有元素插入
    if (res.size() &lt; level + 1) res.add(new ArrayList&lt;>());
    List&lt;Integer> cur = res.get(level);
    cur.add(root.val);
    //继续往下，交给框架即可
    levelOrder(root.left, res, level + 1);
    levelOrder(root.right, res, level + 1);
&#125;
```

BFS解法：

```java

            list.add(cur.val);
            if (cur.left != null) queue.offer(cur.left);

        &#125;
        res.add(list);
    &#125;
    return res;
&#125;
```

**103. 二叉树的锯齿形层次遍历**

本题和二叉树的层次遍历比较相似，但是特殊之处在于逐层打印时需要偶数层正向，奇数层逆向。

所以考虑在放入队列或入栈时对元素的顺序不做特殊处理，仅在每次add进单独的list时进行逆序处理，这样可以有效防止发生“负负得正”这样的后果，并且只做一次逆向也更好理解。

具体如何对add进单独的list做特殊处理呢？可以考虑用双向链表，java天然的LinkedList即可。


DFS解法：
```java
public List&lt;List&lt;Integer>> zigzagLevelOrder(TreeNode root) &#123;
    List&lt;List&lt;Integer>> res = new ArrayList&lt;>();
    levelOrder(root, res, 0);
    return res;
&#125;

private void levelOrder(TreeNode root, List&lt;List&lt;Integer>> res, int level) &#123;
    if (root == null) return;
    if (res.size() &lt; level + 1) res.add(new LinkedList&lt;>()); //使用双向链表，方便插入
    List&lt;Integer> list = res.get(level);
    //通过level的奇偶性判断是尾插还是头插
    insert(root.val, level, list);
    //交给框架处理子节点
    levelOrder(root.left, res, level + 1);
    levelOrder(root.right, res, level + 1);
&#125;

private void insert(int val, int level, List&lt;Integer> list) &#123;
    if (level % 2 == 1) &#123; //如果level是奇数就头插
        list.add(0, val);
    &#125; else &#123;
        list.add(val);
    &#125;
&#125;
```

BFS解法：

**297. 二叉树的序列化与反序列化**

序列化和反序列化没有特别明确的标准，格式不用太纠结，只要序列化后能用自己的反序列化得出原始的二叉树即可。

序列化的思路：通过前序遍历，拼接字符串，遇到null就拼接一个特殊字符串。

反序列化的思路：先将字符串分割成字符串数组，有序放入一个队列中，然后不断从队列中取出元素，通过前序遍历不断连接子节点到root节点上，构成一棵树。遇到特殊字符串之间return作为递归终止条件。

```java
private static final String NN = "NN";
private static final String split = ",";
// Encodes a tree to a single string.
public String serialize(TreeNode root) &#123;
    StringBuilder sb = new StringBuilder();
    buildString(root, sb);
    return sb.substring(0, sb.length() - 1); //去掉最后一个逗号，方便反序列化时切割字符串
&#125;

private void buildString(TreeNode root, StringBuilder sb) &#123;
    if (root == null) &#123;
        sb.append(NN).append(split);
    &#125; else &#123;
        sb.append(root.val).append(split);
        buildString(root.left, sb);
        buildString(root.right, sb);
    &#125;
&#125;

// Decodes your encoded data to tree.
public TreeNode deserialize(String data) &#123;
    Queue&lt;String> queue = new LinkedList&lt;>();
    queue.addAll(Arrays.asList(data.split(split)));
    //通过queue构建树
    TreeNode root = buildTree(queue);
    return root;    
&#125;

private TreeNode buildTree(Queue&lt;String> queue) &#123;
    String s = queue.poll();
    if (NN.equals(s)) &#123; //当前值为null
        return null;
    &#125; else &#123;
        TreeNode root = new TreeNode(Integer.parseInt(s));
        //因为序列化时采用前序遍历，此处直接按顺序进行反序列化
        root.left = buildTree(queue);
        root.right = buildTree(queue);
        return root;
    &#125;
&#125;
```


**104. 二叉树的最大深度**
根节点为空，返回0，这也是递归的终止条件，之后递归的去计算左右子树的最大深度，最终取左右子树最大深度的最大值+1。

```java
public int maxDepth(TreeNode root) &#123;
    if (root == null) return 0;
    return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
&#125;
```


**110.平衡二叉树**

判断一棵树是否是平衡二叉树，就是判断其左右子树的高度差是否小于等于1.

方法1：自顶向下，先判断根节点是否合理，再判断左右子树。
```java
public boolean isBalanced(TreeNode root) &#123;
    if (root == null) return true;
    return Math.abs(maxDepth(root.left) - maxDepth(root.right)) &lt;= 1 && isBalanced(root.left) && isBanlanced(root.right);
&#125;

private int maxDepth(TreeNode root) &#123;
    if (root == null) return 0;
    return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
&#125;
```


方法2：自底向上，提前阻断。

由于方法1会存在大量的重复计算，所以这里对求最大深度的方法进行改造，当左子树或右子树的高度差大于1时，返回-1。
```java
public boolean isBalanced(TreeNode root) &#123;
    return maxDepth(root) != -1;
&#125;

//树的最大高度，如果左右子树高度差大于1，返回-1
private int maxDepth(TreeNode root) &#123;
    if (root == null) return 0;
    int left = maxDepth(root.left);
    if (left == -1) return -1; //剪枝
    int right = maxDepth(root.right);
    if (right == -1) return -1;
    return Math.abs(left - right) > 1 ? -1 : Math.max(left, right) + 1;
&#125;
```
**112. 路径总和**

判断一条从根节点到叶子节点的路径和是否为sum，采用前序遍历的方式。

遍历到当前节点时，如果为null，返回false；否则的话更新sum为减去当前节点的值；然后判断，如果当前已经是叶子节点了，就判断sum是否为0即可，否则递归去判断左子树是否成立或右子树是否成立。

```java
public boolean hasPathSum(TreeNode root, int sum) &#123;
    if (root == null) return false;
    sum -= root.val;
    if (root.left == null && root.right == null) &#123;
        return sum == 0;
    &#125;
    return hasPathSum(root.left, sum) || hasPathSum(root.right, sum);
&#125;

//写法2：本质没有区别
public boolean hasPathSum(TreeNode root, int sum) &#123;
    if (root == null) return false;
    if (root.left == null && root.right == null && root.val == sum) &#123;
        return true;
    &#125; else &#123;
        boolean left = hasPathSum(root.left, sum - root.val);
        boolean right = hasPathSum(root.right, sum - root.val);
        return left || right;
    &#125;
&#125;
```

**113. 路径总和2**

需要存储二叉树总和等于sum的所有根节点到叶子节点的路径，所以使用dfs进行处理。

当到达叶子节点时为一条DFS路线，如果此时路径和等于sum，添加到list中，否则回溯；

当没有到达叶子节点时，继续DFS左右子节点去寻找结果。

需要注意，回溯回上一层时，需要把当前层添加list添加的元素删除。

```java

&#125;

private void pathSum(TreeNode root, int sun, List&lt;List&lt;Integer>> res, List&lt;Integer> list) &#123;

    list.add(root.val);
    if (root.left == null && root.right == null && root.val == sum) &#123; //如果到达终点并有效
        //此处list后续会被修改，所以拷贝一份添加到res
        res.add(new ArrayList&lt;>(list));
    &#125; else &#123; //没达到叶子节点
        pathSum(root.left, sum - root.val, res, list);
        pathSum(root.right, sum - root.val, res, list);
    &#125;
    //考察完当前层，需要回溯回上一层寻找其他解决方案，需要删除当前层list中添加的元素

&#125;
```
**257. 二叉树的所有路径**

直接DFS前序遍历，并将结果保存在list中即可。

方法1：使用字符串保存每条根->叶的路径，使用字符串的不变性，可以保证字符串拼接后无需对原字符串进行回复操作。


**199. 二叉树的右视图**

给定一棵二叉树，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

方法1：BFS。

右视图，所以需要每层最右边非null的元素，那么我们从第一层开始，只把非null的元素入队，入队时先入右节点再入左节点，出队每层第一个元素就是每层最右边非null的元素。

```java
// BFS,每层取最右边的值
public List&lt;Integer> rightSideView(TreeNode root) &#123;
    List&lt;Integer> res = new ArrayList&lt;>();
    if (root == null) return res;
    Queue&lt;TreeNode> queue = new LinkedList&lt;>();
    queue.offer(root);
    while (!queue.isEmpty()) &#123;
        int size = queue.size();
        for (int i = 0; i &lt; size; i++) &#123;
            TreeNode cur = queue.poll();
            if (i == 0) res.add(cur.val);
            TreeNode right = cur.right;
            if (right != null) queue.offer(right);
            TreeNode left = cur.left;
            if (left != null) queue.offer(left);
        &#125;
    &#125;
    return res;
&#125;
```

方法2：DFS

带层数进行DFS，（前序遍历，根->右->左的顺序，这样可以保证每层第一个访问到的元素都是最右边的值）每次进行判断，如果当前结果list的大小和当前层数相等（从0层开始），说明当前层还没有放入list中，放入即可；然后递归右子树，再递归左子树。

```java
List&lt;Integer> res = new ArrayList&lt;>();
public List&lt;Integer> rightSideView(TreeNode root) &#123;
    dfs(root, 0);
    return res;
&#125;

private void dfs(TreeNode root, int level) &#123;
    if (root == null) return;
    if (level == res.size()) res.add(root.val);
    dfs(root.right, level + 1);
    dfs(root.left, level + 1);
&#125;
```
