#### 链表

**2. 两数相加**

输入：(2 -> 4 -> 3) + (5 -> 6 -> 4)
输出：7 -> 0 -> 8
原因：342 + 465 = 807

链表存储整数的倒序，需要得到最终和的倒序的链表，参考小学学过的加法运算。需要注意进位的问题。

```java

    //sum链表的哨兵节点
    ListNode head = new ListNode(0);
    ListNode cur = head;
    //向高位进位
    int carry = 0;
    while (l1 != null || l2 != null) &#123;
        int x = l1 == null ? 0 : l1.val;
        int y = l2 == null ? 0 : l2.val;
        int sum = x + y + carry;
        //赋值进位
        carry = sum / 10;
        //当前位的sum
        sum %= 10;
        //节点拉链
        cur.next = new ListNode(sum);
        cur = cur.next;
        if (l1 != null) l1 = l1.next;
        if (l2 != null) l2 = l2.next;
    &#125;
    //如果最后还有进位，放在最高位即可
    if (carry != 0) cur.next = new ListNode(carry);
    return head.next;
&#125;
```

**23. 合并K个有序链表**

方法1：多路归并。（NlogK,  n是所有的节点个数，k是数组的大小）

每次数组一分为2，从n一分为2一直到1需要log2K次操作，每次分完后合并需要遍历所有的节点一次。

**删除链表的倒数第n个节点**

方法1：找到链表的长度k，那么需要删除的是第（n-k+1）个节点，我们找到它的前驱节点，就是第n-k个节点即可。

```java
public ListNode removeNthFromEnd(ListNode head, int n) &#123;
    if (head == null || n &lt;= 0) return head;
    int k = 0;
    ListNode p = head;
    while (p != null) &#123;
        k++;
        p = p.next;
    &#125;
    int i = k - n;
    if (i == 0) return head.next;
    p = head;
    while (i > 1) &#123;
        i--;
        p = p.next;
    &#125;
    p.next = p.next.next;
    return head;
&#125;
```

**25. K个一组翻转链表**

先判断是否有K个节点，然后翻转前K个节点，递归翻转后面的节点。

```java

    ListNode tail = head;
    for (int i = 0; i &lt; k; i++) &#123;
        //判断k次，如果剩余节点小于k个，不需要反转
        if (tail == null) &#123;
            return head;
        &#125;
        tail = tail.next;
    &#125;
    //此时tail在第k+1的位置
    //反转前k个元素[head,tail-1]
    ListNode newNode = reverse(head,tail);
    //递归反转后面的元素
    head.next = reverseKGroup(tail,k);
    return newNode;

    ListNode cur = head;

        cur.next = prev;

    &#125;
```
