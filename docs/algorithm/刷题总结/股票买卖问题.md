#### 股票买卖问题

[参考labuladong](https://leetcode-cn.com/problems/best-time-to-buy-and-sell-stock-iv/solution/yi-ge-tong-yong-fang-fa-tuan-mie-6-dao-gu-piao-w-5/)

**穷举框架**：

首先是对于递推公式的推导思路，从一维开始，如果发现记录的状态不足以递推就升维。

```
//mp[i]表示第i天的最大利润 return mp[n-1]

//mp[i][j]  j=0表示没有股票，j=1表示拥有股票  i表示第i天
//mp[i][0] = max(mp[i-1][0],mp[i-1][1]+a[i]),mp[i][1] = max(mp[i-1][1],mp[i-1][0]-a[i])

//mp[i][k][j]：k[0->k] k表示交易过的次数，j=0表示没有股票，j=1表示拥有股票  i表示第i天  --->  三维
//i [0,n-1]  k[0,k]  j[0,1]
//mp[i][k][0] = max( mp[i-1][k][0], mp[i-1][k][1]+a[i] )
//mp[i][k][1] = max( mp[i-1][k][1], mp[i-1][k-1][0]-a[i] )
```

利用三维数组进行递推，第一维表示考察到第几天，第二维表示买的次数（一次买+卖算一次交易），第三维记录当前持有股票的状态，0为不持有，1为持有。
```
public int maxProfit(int k, int[] prices) &#123;
    if (prices == null || prices.length &lt;= 1)
        return 0;
    int n = prices.length;
    k = Math.min(k, n >>> 1);
    int[][][] states = new int[n][k + 1][2];
    //初始化条件 k=0时
    for (int i = 0; i &lt; n; i++) &#123;
        states[i][0][0] = 0;
        states[i][0][1] = Integer.MIN_VALUE;
    &#125;
    for (int i = 0; i &lt; n; i++) &#123;
        for (int kk = 1; kk &lt;= k; kk++) &#123;
            //i=0时做特殊判断
            states[i][kk][0] = i != 0 ? Math.max(states[i - 1][kk][0], states[i - 1][kk][1] + prices[i]) : 0;
            states[i][kk][1] = i != 0 ? Math.max(states[i - 1][kk][1], states[i - 1][kk - 1][0] - prices[i]) : -prices[i];
        &#125;
    &#125;
    return states[n - 1][k][0];
&#125;
```

上面的框架在k很大时会出现内存超出的现象，我们分析发现，当k>=n/2的时候，其实和不限制交易次数是同一个问题，进行问题转化即可。

```
public int maxProfit(int k,int[] prices) &#123;
    if (prices == null || prices.length &lt;= 1)
        return 0;
    int n = prices.length;
    //针对k过大内存超出限制进行优化
    if (k >= n/2)&#123;
        return maxProfit(prices);
    &#125;
    int[][][] states = new int[n][k + 1][2];
    //初始化条件 k=0时
    for (int i = 0; i &lt; n; i++) &#123;
        states[i][0][0] = 0;
        states[i][0][1] = Integer.MIN_VALUE;
    &#125;
    for (int i = 0; i &lt; n; i++) &#123;
        for (int kk = 1; kk &lt;= k; kk++) &#123;
            //i=0时做特殊判断
            states[i][kk][0] = i != 0 ? Math.max(states[i - 1][kk][0], states[i - 1][kk][1] + prices[i]) : 0;
            states[i][kk][1] = i != 0 ? Math.max(states[i - 1][kk][1], states[i - 1][kk - 1][0] - prices[i]) : -prices[i];
        &#125;
    &#125;
    return states[n - 1][k][0];
&#125;

//不限制买卖次数
private int maxProfit(int[] prices) &#123;
    int i_0 = 0;
    int i_1 = -prices[0];
    for (int i=1;i&lt;prices.length;i++) &#123;
        int temp = i_0;
        i_0 = Math.max(i_0,i_1+prices[i]);
        i_1 = Math.max(i_1,temp-prices[i]);
    &#125;
    return i_0;
&#125;
```
