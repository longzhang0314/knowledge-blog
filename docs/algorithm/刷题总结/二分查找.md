**34. 在排序数组中找到目标元素出现的第一个和最后一个位置**

注意细节

**287. 寻找重复的数**

寻找大小为n+1的数组中有1-n的数，找到其中一个重复的数返回，数组不能改变，空间O(1).

方法1：先指定一个中间数mid，然后统计小于等于这个中间数的有几个，如果个数大于mid，重复数就在[left,mid]中间，否则在[mid+1,right]中间。

```java
public int findDuplicate(int[] nums) &#123;
    int len = nums.length;
    int left = 0, right = len - 1;
    while (left &lt; right) &#123;
        int mid = left + (right - left) / 2;
        int cnt = 0;
        for (int num : nums) &#123;
            if (num &lt;= mid) cnt++;
        &#125;
        if (cnt > mid) &#123;
            right = mid;
        &#125; else &#123;
            left = mid + 1;
        &#125;
    &#125;
    return left;
&#125;
```
**349. 两个数组的交集**

方法1：两个set,空间换时间。

