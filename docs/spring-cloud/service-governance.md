# 服务治理的复习框架

## 核心问题

微服务治理不是组件罗列，而是回答服务变多以后如何发现、调用、保护、观测和演进。

## 结构

- **发现**：注册中心、实例上下线、健康检查。
- **调用**：负载均衡、超时、重试、幂等。
- **保护**：限流、熔断、隔离、降级。
- **观测**：日志、指标、链路追踪。
- **配置**：动态配置、灰度发布、回滚。
