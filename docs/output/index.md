# 技术输出

这里收纳更偏“文章”和“观点”的内容，例如阶段复盘、面试后的总结、某个专题的学习路线，以及面向个人 IP 的公开表达。

和传统博客不同，这里的文章仍然属于知识库的一部分：可以被目录、标签和站内搜索统一检索，也可以和专题笔记互相引用。

## 写作建议

- 一篇文章只讲清楚一个阶段、一个问题或一个观点。
- 尽量保留上下文：为什么写、当时怎么判断、最后沉淀出什么结论。
- 能链接到专题笔记时，优先链接到对应知识库文章，避免内容孤岛。
